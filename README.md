# Xiangyu Wang Academic Website

A single-file, photo-free, mobile-friendly academic website for GitHub Pages.

## Publish

1. Create a **public** GitHub repository named `USERNAME.github.io` (replace USERNAME with your GitHub username).
2. Upload `index.html` and `Xiangyu_Wang_CV.pdf` to the **root** of that repository.
3. Under **Settings -> Pages**, choose **Deploy from a branch**, **main**, **/(root)** and Save.
4. Open `https://USERNAME.github.io/` once GitHub finishes publishing.

## Edit

Edit `index.html` in any text editor to update publications, email, or styling. Replace `Xiangyu_Wang_CV.pdf` when you update your CV. No build tools or dependencies are required.

Note: the bundled PDF is a re-typeset rendering of the supplied CV content, not the original uploaded PDF. You can replace it with the original using the same filename.
